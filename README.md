# Java & Python Blueprints

Визуализатор и анализатор кода (**Java** и **Python 3.11+**): редактор ↔ граф (CFG / Call Graph / Class Diagram), диагностика
и Big O, обратная генерация кода из графа, декомпозиция монолита, запуск с Quality Gate.

## Поддерживаемые языки
- **Python (3.11+)** — встроенный парсер на базе `ast`, полный статический анализ AST, генерация CFG/Call Graph/Class Diagram, расчет Big O, детекция дефектов, декомпозиция модулей, запуск кода с интерактивной WebSocket консолью и Quality Gate.
- **Java (≤ 8)** — парсер на базе `javalang`, компиляция через `javac` и выполнение в изолированной песочнице.
- Быстрый переключатель `[Java | Python]` в шапке приложения + автоматическое распознавание языка при загрузке `.java` / `.py`.

## Запуск через Docker

```bash
docker compose up --build        # UI: http://localhost
```

## Локальная разработка

```bash
# backend (Python 3.11+, опционально JDK 11+ в PATH для Java)
cd backend && python3 -m venv venv && source venv/bin/activate
pip3 install -r requirements.txt
uvicorn main:app --reload --port 8000
python -m pytest                 # тесты

# frontend
cd frontend && npm install && npm run dev   # http://localhost:3000, /api проксируется на :8000
```

## Как пользоваться
1. Загрузите `.java` или `.py` (кнопка или drag-n-drop) — либо переключите язык в шапке и правьте код в редакторе, граф обновляется через 500 мс.
2. Наведите курсор на строку ↔ узел графа; клик по узлу переносит курсор в редактор.
3. Двойной клик по узлу CFG → правка текста → Enter → код функции/метода перегенерируется.
4. **Run** (Ctrl+Enter) — запуск в интерактивной консоли внизу (WebSocket): вывод идёт потоком, ввод для
   `Scanner` / `input()` набирайте прямо в консоли; Stop/EOF — кнопки. **Compare** повторяет ваш ввод из последней сессии; **Compare** — вывод оригинала vs текущего кода; **Decompose** (Ctrl+D) —
   предложение файлов, Quality Gate и zip.
5. Undo/Redo: Ctrl+Z / Ctrl+Y.

## Ограничения
- Сервер хранит последний разобранный код в памяти (демо на одного пользователя).
- Парсер Java — `javalang` (Java ≤ 8 синтаксис; без records/switch-выражений/var в лямбдах). Парсер Python — стандартный `ast` (полная поддержка Python 3.11+).
- Декомпозиция переносит `static`-методы в Java и функции в отдельные модули в Python; вложенные static-классы становятся файлами.
- Правка узла графа поддерживает текст операторов, условий циклов/if, return/throw, catch/except-параметры.
- Запуск: для Python используется локальный интерпретатор; для Java — `JAVA_SANDBOX_MODE=subprocess` (по умолчанию, таймаут 10 с, `-Xmx256m`) или `docker` (изоляция без сети, 256 МБ).

## AI-подсказки (Gemini, опционально)
```bash
cp backend/.env.example backend/.env   # LLM_ENABLED=true, ключи и прокси — см. комментарии в файле
```
- **Кнопка ✨ AI** у дефекта — объяснение и исправленный фрагмент; **✨ AI-совет** во вкладке «Декомпозиция».
- **Авто-ИИ:** через 5 секунд после последней правки кода показывается плашка «ИИ-модель смотрит, как улучшить ваш
  код…», затем в шапке появляется кнопка «✨ N идей» → панель с советами (клик по совету — переход к строке).
  Новая правка сбрасывает таймер и отменяет запрос. Отключается галочкой «Авто-ИИ» (запоминается в браузере).
- **Ключи:** `GEMINI_API_KEY=k1,k2,k3` (список через запятую); `GEMINI_KEYS_COUNT` — использовать только первые N.
- **Прокси:** `GEMINI_PROXIES=ip:login:password,ip:port:login:password,…` — запросы к Gemini идут только через них.
- **Ретраи:** при ошибке запрос повторяется с другим случайным ключом и прокси; модель облегчается (`GEMINI_MODEL` → `gemini-2.5-flash` → `gemini-2.5-flash-lite`).
- **Применение правок:** модель возвращает пару «фрагмент → замена» (+ недостающие `import`). Проверяется синтаксис и компиляция перед показом кнопки «Применить».
- Без LLM кнопки «✨ AI» дают статические советы из базы паттернов.

## Безопасность
- Сервис выполняет присланный код. В `subprocess`-режиме это **не песочница** — только для локальной разработки;
  для доступа извне используйте `JAVA_SANDBOX_MODE=docker`. Авторизации нет (демо на одного пользователя).
- Вызовы API и WebSocket принимаются только с разрешённых origin (`ALLOWED_ORIGINS`).
