# Java Blueprints — описание решения

Веб-среда, которая понимает программу как код и как граф, помогает её улучшить и доказывает, что поведение
сохранилось. Кейс Axenix «Визуальная среда программирования», 48-часовой хакатон.

**Ключевой контракт кейса выполнен:** после правки узла графа, правки ИИ или декомпозиции приложение само
компилирует и запускает исходную и новую версии и сравнивает вывод. Итог — вердикт «поведение сохранено» или
diff расхождения.

## 1. Дизайн интерфейса

### Концепция
Тёмная «IDE-подобная» среда: почти чёрный холст, контент в карточках с тонкими границами, один яркий акцент —
оранжевый, как у Axenix. Акцентом выделено только главное: кнопка «Запустить», активные элементы, логотип,
условия на графе. Всё остальное приглушено, чтобы взгляд шёл к коду, графу и найденным проблемам. Декоративных
градиентов и фоновых картинок нет: «бренд» создают контраст и акцент.

Есть светлая тема (кнопка ☀/☾ в шапке) с тем же набором токенов.

### Цвета узлов графа (легенда над схемой)

| Тип узла | Цвет (тёмная тема) |
|---|---|
| Начало | бирюзовый `#2dd4bf` |
| Условие / switch | оранжевый `#fb923c` |
| Цикл | синий `#60a5fa` |
| try / catch / finally | фиолетовый `#a78bfa` |
| Операция | серый `#a3a3a3` |
| Шаг стрима | оранжевый, моноширинный текст |
| Возврат / конец / throw | розовый `#f472b6` |

Повтор цикла рисуется пунктирной стрелкой. Ветки условий подписаны «да / нет». Узел с дефектом получает
предупреждающий значок, а узлы получают бейдж сложности: например `O(n²)` на старте метода.

### Типографика
- **Inter Variable** — весь интерфейс: заголовки 600–700, текст 400–500, подписи разделов капсом с разрядкой
  («ДЕФЕКТЫ», «ПРОЕКТ (JAVA)»).
- **JetBrains Mono Variable** — код в редакторе, текст узлов графа, консоль, бейджи Big O.

Шрифты встроены в сборку (`@fontsource`) и не зависят от CDN.

### Форма и движение
- Скругления: 8 px у кнопок и чипов, 10 px у карточек, 16 px у модальных окон; pill-форма у счётчиков.
- Шапка высотой 58 px, кнопки 28–36 px.
- Анимации короткие (0.15–0.25 с, кривая `cubic-bezier(.2,.7,.2,1)`): появление вкладок, тостов и модалок,
  shimmer-скелетоны, пока ИИ думает, пульс у активного запуска.

## 3. Стек

| Слой | Технологии |
|---|---|
| Фронтенд | React 18, TypeScript 5.6, Vite 6, Zustand 5 (состояние), React Flow 11 (граф), elkjs 0.12 (раскладка графа с минимумом пересечений, ортогональные рёбра), Ace (редактор), axios, diff, html-to-image (экспорт графа в PNG), шрифты Inter и JetBrains Mono |
| Бэкенд | Python 3.11, FastAPI, Pydantic 2, uvicorn, WebSocket (интерактивная консоль) |
| Разбор Java | собственный форк `javalang`, расширенный до Java 17. Для Python используется стандартный модуль `ast` |
| Выполнение | JDK 17 (`javac` / `java`) в отдельном процессе с таймаутом и лимитом памяти; режим docker-песочницы без сети |
| ИИ (опционально) | Google Gemini (ротация ключей и прокси, откат на запасные модели) или локальный Ollama |
| Тесты | pytest (бэкенд), vitest (фронтенд) |
| Инфраструктура | Docker Compose: бэкенд (Python + Temurin JDK 17) и фронтенд (nginx раздаёт сборку и проксирует `/api`) |

### Архитектура в одном абзаце
Браузер отправляет код на `/api/parse`. Бэкенд строит JSON-AST с точными позициями каждого оператора и хранит его
в сессии вкладки. Из AST строятся CFG метода (детерминированные id узлов `n0…`), граф вызовов и диаграмма классов,
считаются Big O и дефекты. При правке узла `/api/generate` пересобирает CFG, находит изменённые метки и заменяет в
исходнике только их фрагменты. `/run/compare` и `/quality-gate` компилируют и запускают обе версии и сравнивают
вывод (временные метки маскируются).

## 4. Сделано сверх ТЗ

| Фича | Что даёт |
|---|---|
| **Python 3.11+ как второй язык** | Тот же путь (граф, Big O, дефекты, правка узлов, декомпозиция на модули, запуск, Quality Gate) для Python. Переключатель `Java / Python` в шапке, язык файла определяется автоматически |
| **Покрытие кода при запуске** | Цветные полосы у номеров строк (выполнилась / частично / нет) и вкладка «Покрытие» со сводкой по строкам, ветвям и условиям. Покрытие копится между запусками и сбрасывается при правке |
| **ИИ-ревью с готовыми правками** | Через 5 с после последней правки ИИ предлагает улучшения. Каждая правка — пара «фрагмент → замена»; её проверяют компиляцией до показа и ещё раз при применении. Правка не может добавить ошибок компиляции |
| **«Исправить с ИИ» для ошибки javac** | Одна кнопка у ошибки компиляции. Правка принимается, только если она убирает именно эту ошибку |
| **Big O «до → после» правок ИИ** | Пересчёт сложности затронутых методов. Если правок несколько, считается их совместный эффект |
| **Ожидаемый эффект без ИИ** | Правило диагностики само знает, какой станет сложность после рекомендации |
| **Extract Class при декомпозиции** | Кроме статических методов переносится состояние объекта: замкнутая группа полей и методов уходит в класс-компонент, а монолит делегирует ему с прежними сигнатурами |
| **Интерактивная консоль** | Вывод идёт потоком через WebSocket, ввод для `Scanner` / `input()` набирается прямо в консоли, есть кнопки Stop и EOF |
| **Сравнение запусков** | Вкладка «Сравнение» показывает два последних запуска файла с diff и пометкой «Ввод отличался» |
| **Многофайловый проект** | Дерево файлов и папок, вкладки редактора, создание и переименование. Проект хранится в браузере (IndexedDB) и переживает перезагрузку |
| **Многопользовательский режим** | Отдельная сессия на каждую вкладку браузера, лимиты на создание сессий, автоочистка |
| **Безопасность** | Docker-песочница без сети с лимитами, минимальное окружение дочернего процесса (ключи ИИ ему недоступны), проверка Origin, ключи и пароли прокси вычищаются из логов |
| **Стримы как узлы графа** | `xs.stream().filter(...).map(...).collect(...)` раскладывается на отдельные редактируемые узлы |
| **Удобства** | Undo / Redo (Ctrl+Z / Ctrl+Y), горячие клавиши (Ctrl+Enter — запуск, Ctrl+D — декомпозиция), экспорт графа в PNG, скачивание файла или zip изменённых файлов, светлая тема, изменяемые колонки |

## 5. Ограничения

- Синтаксис Java — до версии 17. Образцы в `switch` из Java 21 (`case Type t ->`) не поддерживаются.
- Switch-выражение, анонимный класс и лямбда с блоком показываются в CFG одним узлом с исходным текстом.
- Декомпозиция переносит то, что можно перенести без изменения поведения. Методы, работающие с общим состоянием
  объекта, остаются в фасаде, и интерфейс прямо говорит об этом.
- Сессия интерактивной консоли длится не больше 10 с.
- Режим запуска «subprocess» (по умолчанию) — не песочница. Для изоляции есть режим `JAVA_SANDBOX_MODE=docker`.
- Функции ИИ требуют ключа Gemini или локального Ollama; без них работают статические подсказки.
