## C. Файлы: создание, переименование, удаление; хранение в браузере

`frontend/src/examples/`) никогда не меняются. У разных пользователей может быть разное содержимое. Новый
пользователь (или очищенный браузер) получает стандартные примеры в исходном виде.

## D. Стрелки на графе с минимумом пересечений

Полностью без пересечений граф не всегда можно нарисовать: вложенные циклы, `break`/`continue`. Цель —
минимум пересечений, и стрелки не идут сквозь узлы.
- [x] Заменить раскладку dagre (`hooks/useSync.ts`, `layoutGraph`) на ELK (`elkjs`, layered, ортогональная
      маршрутизация рёбер, минимизация пересечений, обратные рёбра циклов с отдельного порта).
      Зафиксировать точную версию пакета.
- [x] Рисовать рёбра по точкам маршрута ELK: свой тип ребра React Flow с ломаной по `sections`.
- [x] Метки рёбер `true`/`false`/`back` — на сегментах, не на узлах.
- [x] Сохранить направления: CFG и граф вызовов — сверху вниз, диаграмма классов — слева направо.
- [x] Сохранить размеры узлов (в том числе узлы стримов).
- [x] Раскладка асинхронная (ELK возвращает Promise): не показывать устаревший результат, если код
      изменился за время расчёта.
- [x] Сравнить до и после на примерах `Calculator.java`, `Streams.java`, `Demo.java` и Python-примерах:
      пересечений меньше, ни одна стрелка не проходит через узел. Скриншоты — в отчёт.
- [x] Тест (vitest): раскладка детерминирована; у всех рёбер есть точки маршрута.
