## Этап 5 — Сложность «сейчас → после ИИ»

- [ ] Для каждой применимой ИИ-правки считать Big O методов на пропатченном коде (`bigoBefore` / `bigoAfter`)
- [ ] Несколько советов на метод: применять вместе, при конфликте брать лучший
- [ ] Ожидаемое ускорение по формуле при n ≈ 1000, округление (~2×, ~5×, ~10×, ~100×, ~1000×); без ускорения при той же сложности; красным, если стало хуже

- [ ] Тесты
