## Отложено (не блокирует слияние)

- README.md:77-79: пункт про лимит сессии 10 с вставлен над строкой-продолжением пункта «Запуск».
- `/api/ai/fix` угадывает язык по тексту, если в запросе нет `language` (фронтенд его передаёт).
- `_generate_patches` по умолчанию `language="java"`.
- Глубокая цепочка вызовов (~300) → `RecursionError` в `analyze_ast`.
- Парсер:
  - `case (\n 1|2\n):` теряет `case (`;
  - def внутри верхнеуровневого `if`/`try` называется `main.helper`;
  - одинаковые вложенные def дают одинаковые id;
  - правка заголовка с `\` слегка сдвигает отступ.
- CFG: у `while True` есть выход `else`; `return` в `try` идёт мимо `finally` (как в Java).
- Дефекты: правило конкатенации не учитывает порядок присваиваний; имена из строковых аннотаций считаются
  неиспользуемыми импортами.
- Декомпозиция:
  - у перенесённого класса меняется `__module__`;
  - `from m import *` ставится в начало модуля;
  - в `main.py` остаются импорты, нужные только перенесённым единицам;
  - нет пустой строки после добавленных `from x import`.
- Покрытие Python:
  - пробы не ставятся на `async for`, `if` в comprehension, guard в `match`, `assert`;
  - `elif` подписан как «if»;
  - тело класса считается в объемлющем контексте;
  - метод-генератор засчитывается на первом `next()`;
  - `KeyboardInterrupt` → код 1;
  - `_loader_main` не используется;
  - соседние модули могут затенить stdlib-импорты загрузчика;
  - порядок проб в docker сверяется только по числу слотов;
  - ошибка записи в `prepare_python` оставляет tmp.
- Java: если в `Cov.java` не удаётся mmap, покрытие молча показывает 0% (старое поведение).
- Тесты: предупреждение об устаревании Starlette TestClient; `dataclasses.replace` ничего не делает; голый `return`
  вместо skip в тесте symlink.
- `calculator.py`: константа `OPERATORS` не используется.
- Docker-режим (запуск и покрытие) проверен только по аргументам команды: Docker на этой машине не запущен.
